# Recursos de terceiros

## Mo'Creatures

Esta versão contém geometria, texturas, áudio e metadados adaptados de
[multision/mocreaturesdev](https://github.com/multision/mocreaturesdev),
cujo repositório declara GNU GPL v3.

Créditos de origem: DrZhark, BlockDaddy, Bloodshot, multision, TheidenHD,
ACGaming, IcarussOne e xJon.
O modelo do lagarto furtivo também conserva o crédito de Daveyx0, presente no
cabeçalho do arquivo Java original.

- [Licença integral](resources/mocreatures/COPYING).
- [Escopo e alterações da adaptação](resources/mocreatures/README.md).
- [Commit, arquivos e hashes](resources/provenance/mocreatures.json).
- [Código Java original preservado](resources/provenance/mocreatures-java-source.zip).

As fontes Rust desta versão, o importador e os catálogos fazem parte das
alterações necessárias para reconstruir a adaptação. A distribuição de uma
versão derivada deve atender às condições da GPL, inclusive disponibilização
do código-fonte correspondente e preservação dos avisos aplicáveis.
